Overview

The previous portfolio documents an operational Android application for vehicle-related workflows, alongside original operator app screenshots.

02

The problem

Operators repeat the same vehicle and payment tasks frequently. Extra steps and unclear network states interrupt that work.

03

The solution

Camera-assisted identification, server-backed processing and payment flows in a reusable Compose interface.

Android development & integration

  • Session and network state handling
