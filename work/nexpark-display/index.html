02 / Project field notes

NexPark Display

A parking facility display that turns system states into clear instructions for the driver. Including the moments when the connection fails.

Android TV parking displayConnected display system
Project field notes
OverviewThe problemThe solutionMy roleTechnologiesTechnical decisionsFeaturesThe challengeOutcomeEvidence & access
01

Overview

NexParkDisplay is a native Java application for Android-based parking displays. It presents driver-facing instructions while the connected parking system processes a vehicle journey.

02

The problem

A driver waiting at a parking facility needs a short, readable message. Connection loss and older Android hardware make that simple interaction a real engineering constraint.

03

The solution

A focused television interface with distinct states for connecting, fee calculation and connection failure. Layout and text fitting are handled for a display viewed from a distance.

04

My role

Android TV application development & system integration

05

Technologies

Java · Android TV · Android SDK · Socket.IO · API 19+

06

Technical decisions

The inspected project uses native Android views, Java, a Socket.IO connection and an API client. Device profiles, text fitting and legacy TLS handling have separate responsibilities. Its declared minimum SDK is 19; that declaration is not a claim that every API 19 device was certified.

07

Features

  • Driver-facing calculation and connection states
  • Native Android display interface
  • Socket-based system communication
  • Text fitting for display layouts
  • Compatibility paths for older Android devices
08

The challenge

Supporting varied display hardware and older Android versions while keeping the messages legible. Device-specific update behavior needs testing on the actual hardware.

09

Outcome

A separate Android display application is confirmed in source. This portfolio demonstrates two reconstructed message states; a production screenshot and deployment metrics were not available.

10

Evidence & access

Interface study recreated from verified source strings. It is not a product screenshot, a live connection or a full app emulator.

The source is private. The description shares implementation context without service addresses or customer data.
