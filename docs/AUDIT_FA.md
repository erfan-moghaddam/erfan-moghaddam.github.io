## اطلاعات واقعی و قابلیت‌های حفظ‌شده

نام Erfan Moghaddam، تمرکز Android/Kotlin/Compose، توسعه وب، سیستم‌های پارکینگ، آمادگی همکاری ریموت و موقعیت ایران در محتوای قبلی وجود داشتند. ایمیل، تلفن، GitHub و LinkedIn فعلی از همان صفحه حفظ شدند. هر دو رزومه و تمام تصاویر اصلی بدون تغییر بایت باقی ماندند.

بخش‌های قبلی: Hero، پروژه‌های منتخب، کارهای عمومی، قابلیت‌ها، فرآیند و ارتباط. پروژه‌های مستند: اپ مصرف‌کننده NexPark، اپ عملیاتی، نمایشگر Android TV، پنل مدیریت وب، Crypto Signal API و خود پورتفولیو.

قابلیت‌های قبلی شامل EN/FA با RTL، انتخاب تم و ذخیره ترجیح، رزومه متناسب با زبان، منوی موبایل، نشانگر بخش فعال، reveal اسکرول و انتخاب دو وضعیت TV بودند. زبان و تم، رزومه‌ها، navigation و تغییر وضعیت TV حفظ و بازپیاده‌سازی شدند. نشانگر پیشرفت عمومی اسکرول حذف شد تا نقش بیشتری به محتوای واقعی داده شود؛ هیچ مسیر اصلی حذف نشد.

لینک‌های انتشار Android، APK، App Store، SibApp و وب‌سایت محصول حفظ شدند. سهم توسعه iOS به عرفان نسبت داده نشده است.

## یافته‌های تجربه و طراحی

1. قاب‌های گرد، سطح‌های نیمه‌شفاف، کارت‌های مشابه، رنگ تأکیدی سبز و گرادیان‌های پس‌زمینه، هویت را به قالب رایج توسعه‌دهندگان نزدیک می‌کردند.
2. اپ موبایل، نمایشگر TV و پنل وب تقریباً از یک الگوی ارائه استفاده می‌کردند؛ تفاوت مسئله و محدودیت هر محصول برجسته نبود.
3. بازسازی اپ عملیاتی و جدول عضویت کنار تصویر واقعی قرار داشتند. توضیح منشأ تصاویر وجود داشت، اما تشخیص آن به خواندن متن‌های کم‌اهمیت وابسته بود.
4. تصاویر باارزش موجود عمدتاً در ارائه اصلی استفاده نمی‌شدند؛ اپ منتشرشده بیشتر با splash معرفی می‌شد تا قابلیت‌های آن.
5. مطالعات موردی URL مستقل و روایت فنی ده‌بخشی نداشتند.
6. مخفی‌بودن پیش‌فرض عناصر reveal به JavaScript وابسته بود؛ در نسخه جدید هیچ محتوای ضروری برای انتظار انیمیشن مخفی نمی‌شود.
7. منوی قبلی مدیریت صریح چرخه focus نداشت. منوی جدید native dialog است و چرخه Tab/Shift+Tab، Escape و بازگشت focus دارد.
8. SEO اولیه شامل title، description، canonical، Open Graph متنی و Person schema بود. تصویر اشتراک‌گذاری، sitemap و robots مستقل در سورس نبودند.
