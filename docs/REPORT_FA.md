SHA-256 آرشیو کامل:

```text

```

checkout اولیه از GitHub clone شد و تمیز بود؛ در این محیط تغییر commitنشده یا untracked وجود نداشت. بکاپ شامل وضعیت قابل دسترسی مخزن است و نمی‌تواند تغییرات ذخیره‌نشده روی دستگاه دیگری را پوشش دهد. پیش از ویرایش اپلیکیشن، نسخه استخراج‌شده و Git آن بررسی شدند. مجوزهای اصلی در tar ثبت شده‌اند؛ فیلتر امن استخراج، مجوز گروه/دیگرانِ سه فایل را عادی‌سازی کرد، ولی بایت هیچ فایل تغییر نکرد.

برای بازیابی، در مسیر جدید و خالی کار کنید؛ هیچ reset یا پاک‌سازی روی پوشه کاری لازم نیست:

```sh
mkdir /workspace/recovered-before-2026
tar -xzf /path/to/portfolio-complete.tar.gz -C /workspace/recovered-before-2026
git -C /workspace/recovered-before-2026/portfolio fsck --full
```

روش مستقل Git:

```sh
git clone /path/to/repository.bundle /workspace/recovered-git-before-2026
```

## ۲. ممیزی و تحقیق

سایت قبلی Next.js نبود؛ HTML، CSS و JavaScript ایستا در یک فایل ۳۱۹۷خطی داشت. معماری سبک آن حفظ شد و به تولید صفحات استاتیک با اجزای مشترک ارتقا یافت. جزئیات فناوری، داده‌های حفظ‌شده، URLها و شواهد سورس در [ممیزی فارسی](AUDIT_FA.md) آمده‌اند.

۱۱ نمونه دارای شواهد بصری تحلیل شدند: Brittany Chiang، Corentin Bernadou، Stefan Vitasović، Eloy Benoffi، Dennis Snellenberg، Rauno Freiberg، Paco Coursey، Josh W. Comeau، Lee Robinson، Maggie Appleton و Rafał Pastuszak. برای Corentin، Stefan و Eloy شرح‌های تاریخ‌دار ۲۰۲۵/۲۰۲۶ نیز خوانده شدند؛ سایر مرجع‌های مهندسی به‌صورت فعلی در ۲۰۲۶ مشاهده شدند و سال طراحی موارد نامعلوم حدس زده نشده است.

برای هر نمونه، هویت، تایپوگرافی، layout، Hero، تعامل، motion، پروژه، navigation، موبایل، عملکرد، دسترس‌پذیری و روایت تحلیل شده‌اند. عملکرد و دسترس‌پذیری مرجع‌ها به‌عنوان ممیزی کامل یا امتیاز عددی گزارش نشده‌اند. مواردی مانند Bruno Simon که capture قابل اتکا نداشتند، در شمار ۱۱ نمونه نیستند.

لینک تک‌تک منابع، حدود مشاهده، منابع مسدود و مقایسه سه مسیر در [تحقیق طراحی](RESEARCH_FA.md) ثبت شده‌اند.

از سه مسیر Field Notes، Signal Room و Product Editions، مسیر **Engineering Field Notes × Interactive Digital Systems** انتخاب و اجرا شد. اصل انتقال‌یافته، وضوح نقش، ارائه شواهد و انسجام گرافیکی است. layout، کد، asset یا حرکت اختصاصی سایت دیگری کپی نشده است.

## ۴. تغییرات فنی و فایل‌ها

فایل قدیمی `index.html` به خروجی تولیدشده از سورس تفکیک‌شده تبدیل شد. هر ۱۰ تصویر JPEG و هر دو PDF اصلی در repository و بسته استاتیک با بایت اولیه حفظ شده‌اند.

فایل‌های اصلی جدید:

```text
src/content.mjs              داده واقعی و محتوای دو زبان
src/components.mjs           اجزای مشترک و قالب صفحه‌ها
src/site.css                 سیستم طراحی، responsive، RTL و reduced motion
src/app.js                   تعامل‌ها و navigation
src/theme.js                 آماده‌سازی ترجیح پیش از paint
scripts/build.mjs            تولید صفحات و بسته dist
scripts/serve.mjs            سرور preview محلی
tests/content.test.mjs       اعتبارسنجی محتوا و حفظ داده
tests/portfolio.spec.mjs     آزمون مرورگر و دسترس‌پذیری
playwright.config.mjs        پیکربندی Chromium
eslint.config.mjs            lint
tsconfig.json                بررسی strict کد مرورگر JavaScript
package.json / lockfile      فرمان‌ها و نسخه‌های ثابت ابزارها
assets/fonts/                فونت‌های بهینه و مجوزها
assets/images/               ۱۱ تصویر WebP، شامل capture جدید پنل
assets/favicon.svg           نشان جدید
assets/social-preview.png    تصویر اشتراک‌گذاری ۱۲۰۰×۶۳۰
docs/                        ممیزی، تحقیق، گزارش و manifest فایل‌های اصلی
```

خروجی‌های تولیدشده: دو صفحه اصلی EN/FA، هشت صفحه مطالعه موردی، `404.html`، `sitemap.xml`، `robots.txt`، `.nojekyll` و نسخه مرورگری CSS/JS. اطلاعات پروژه از رفتار و ظاهر جدا شده است. `dist/` خروجی بازتولیدپذیر است و وارد Git نمی‌شود.

وابستگی production: **صفر**. ابزارهای توسعه با نسخه ثابت: Playwright 1.65.1، axe 4.14.0، ESLint 10.15.0 و TypeScript 7.0.2. Lighthouse 13.6.0 فقط ابزار QA محیط بود و وابستگی سایت نیست. نصب و `npm ls` موفق بودند؛ `npm audit` در زمان بررسی صفر آسیب‌پذیری گزارش کرد.

CSS و JavaScript تحویلی جمعاً حدود **۷۱٫۸ KiB بدون فشرده‌سازی** هستند. تصویر پروفایل از ۱٬۷۵۲٬۱۷۴ بایت به مشتق WebP برابر ۱۶٬۳۳۲ بایت رسید؛ اصل JPEG باقی ماند. فونت‌ها محلی‌اند، تصاویر اندازه مشخص و lazy loading دارند و قاب‌ها پیش از دانلود تصویر اندازه می‌گیرند.

SEO شامل title/description، canonical، hreflang، Open Graph، Twitter card، تصویر اشتراک‌گذاری، sitemap، robots و Person/CreativeWork structured data است. تمام fragmentهای مهم قبلی و آدرس رزومه‌ها و تصاویر اصلی حفظ شده‌اند؛ جابه‌جایی مسیر موجودی رخ نداده که redirect لازم داشته باشد.

### Lighthouse — آزمایش محلی

## ۶. بازبینی بصری و قبل/بعد

تصاویر Desktop با عرض ۱۴۴۰ و Mobile با عرض ۳۹۰، برای Hero، Projects و Contact در نسخه اولیه و جدید ثبت شدند. شش تصویر مقایسه کنارهم و capture کامل نسخه جدید آماده‌اند. تم تیره، فارسی، منو و مطالعه موردی نیز ثبت و بازبینی شدند. قبل از full-page capture، تصاویر lazy به‌صورت واقعی load/decode شدند تا قاب خالی به‌عنوان خروجی نهایی ارائه نشود.

بازبینی نهایی روی وضوح تخصص Android، تفاوت هویت، کانون‌بودن پروژه‌ها، فاصله‌گذاری، نمایش موبایل و ضرورت تعامل‌ها انجام شد. loader اجباری، custom cursor، جدول ساختگی داشبورد و افکت سنگین سه‌بعدی وارد نسخه جدید نشدند.

## ۷. محدودیت‌های باقی‌مانده

1. تصویر واقعی محیط تولید Android TV موجود نبود؛ پیش‌نمایش آن بازسازی دارای برچسب است. اپ Android TV در emulator یا سخت‌افزار واقعی این پروژه اجرا نشده است.
2. تصویر داشبورد واردشده با داده واقعی در دسترس نبود؛ capture واقعی صفحه ورود نمایش داده می‌شود. هیچ آمار یا جدول ساختگی به آن اضافه نشده است.
3. پروژه عملیاتی و Crypto API بر اساس اطلاعات مستند پورتفولیوی قبلی حفظ شدند؛ ممیزی مستقل کامل سورس آن‌ها ادعا نمی‌شود.
4. LinkedIn دسترسی خودکار را مسدود کرد. لینک دقیق ارائه‌شده توسط مالک حفظ شده است.
5. تست میدانی، دستگاه واقعی، Safari و screen reader انسانی انجام نشده‌اند.
6. مرورگر headless و preview محلی اجرا شدند. ابزار forwarding برای ارائه URL قابل دسترس از دستگاه شما در این محیط وجود نداشت؛ لینک عمومی ساختگی ارائه نشده است.
7. بکاپ، وضعیت مخزن متصل را پوشش می‌دهد؛ کار ذخیره‌نشده خارج از آن در دسترس نبود.

## ۸. اجرا و تحویل

```sh
npm ci
npm run dev
```

آدرس اجرای محلی `http://localhost:4174` است. برای تغییر محتوا، `src/` را ویرایش و `npm run build` اجرا کنید. دستورها و ساختار در [README](../README.md) توضیح داده شده‌اند.
